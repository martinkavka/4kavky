# 4 Kavky

Memoriální web nakladatelství deskových her 4 Kavky (Martin + Alice Kavkovi), které jsme zavřeli. Drží na jednom místě blog o deskovkách a slovník deskoherního slangu — aby ta léta práce zůstala dohledatelná.

- **Doména:** [www.4kavky.cz](https://www.4kavky.cz)
- **Stack:** plain HTML/CSS/JS, bez build stepu a závislostí. Blog se generuje z Markdownu (`stary-web/blog/*.md`), vlastní typografický engine na české mezery a pomlčky (`scripts/typography.py`).
- **Deploy:** Cloudflare Pages.

Bez trackingu. Design tokeny (barvy, typografie) v CSS.
